# Security policy

Do not open a public issue containing credentials, private context, review manifests derived from real user data, or policy files that reveal sensitive operations.

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/amiencoy/axionorm/security/advisories/new). Include a minimal synthetic reproducer and affected version.

Axionorm is an experimental reference implementation, not a semantic DLP guarantee. Human review remains part of its security boundary.
